# Portfolio — Trần Trọng Chiến

Static portfolio for [nezu.id.vn](https://nezu.id.vn), hosted by GitHub Pages.

## Update

Edit `index.html`, `styles.css`, or `script.js` and push to `main`. GitHub Pages publishes the repository root. The `CNAME` file binds the custom domain; `.nojekyll` keeps the static files unchanged.

Project descriptions are sourced from public repositories and commit history listed in [PROJECT_SOURCES.md](PROJECT_SOURCES.md).
