# Nguồn nội dung portfolio

Nội dung trang được đối chiếu từ mã nguồn và lịch sử commit công khai, không lấy các tuyên bố trong README hồ sơ `blueMonkey23/blueMonkey23` làm nguồn.

- GreenMap Backend: https://github.com/HouHackathon-CQP/GreenMap-Backend ; lịch sử commit của blueMonkey23: https://github.com/HouHackathon-CQP/GreenMap-Backend/commits?author=blueMonkey23 . Trang ghi rõ đây là dự án nhóm.
- Circle K Microservices Demo: https://github.com/blueMonkey23/QuanLyBanHangCircleK ; `gateway/`, `services/`, `ui/src/App.jsx`, `db/v2/`.
- CultureLinkVN: https://github.com/blueMonkey23/CultureLinkVN ; `index.html`, `app.js`, `scripts/`, `data/`.
- Task & Progress API: https://github.com/blueMonkey23/BaoCaoLaravel ; `routes/api.php`, `app/Http/Controllers/Api/`.
- Quản lý nhân khẩu: https://github.com/blueMonkey23/QuanLyNhanKhau1 ; các Windows Forms trong thư mục dự án.
- AI Photo Restoration: https://github.com/blueMonkey23/Aiphotorestorationapp ; `src/app/App.tsx` thể hiện UI, không có pipeline xử lý ảnh trong repository. Trang chỉ gọi là nguyên mẫu giao diện.

Các hình trong thẻ dự án là minh họa bằng HTML/CSS, không phải ảnh chụp ứng dụng.
